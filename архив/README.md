# Архив

Старый код, который больше не собирается и не запускается: только источник идей (камера, шейдеры, сетки, редактор).

- `src` — редактор карт, сетка, шейдеры доски.
- `src-exp` — прошлая попытка блока и трёхмерной сетки (`cube.ts` — первый блок травы на JPG-текстурах).
- `tests`, `tests-exp` — тесты к ним.
- `public` — карты и JPG-тайлы.
- `index.html`, `cube.html`, `exp.html`, `vite.config.ts`, `tsconfig.json` — прежние входы и настройки (алиасы `@shared`, `@editor`, `@core` и т. д.).

- `ro-block-style` — первый блок травы: каменное тело плюс оболочка травы с рваной бахромой, всё на трёх нарисованных текстурах (`public/tex`). Выглядит как земля из Ragnarok Online. Запускается как отдельный проект: `index.html` и `src` лежат рядом, текстуры в `public/tex`.

Папка исключена из `tsconfig.json` и из тестов.
